# Homebrew Tap for portree

This is a [Homebrew](https://brew.sh/) tap for [portree](https://github.com/fairy-pitta/portree).

## Installation

```bash
brew install fairy-pitta/tap/portree
```

## What is portree?

**portree** is a Git Worktree Server Manager that automatically manages multiple dev servers per git worktree with automatic port allocation, environment variable injection, and `*.localhost` subdomain routing.

For more information, see the [portree repository](https://github.com/fairy-pitta/portree).
